# Evidencias
Guardar solo material revisado apto para el repositorio: capturas, salidas depuradas y resultados de laboratorio. Usar nombres E01, E02, etc. y vincularlos con el registro de pruebas. No incluir secretos ni datos de compañeros sin su permiso. Las claves públicas se distinguen de las privadas; revisar su publicación de forma deliberada. Los patrones de .gitignore son una ayuda, no una garantía de ausencia de secretos.

Ficha: ID | objetivo | fecha | herramienta/versión | pasos | resultado esperado | resultado observado | éxito/fallo | evidencia | explicación.
